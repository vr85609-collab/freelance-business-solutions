# Aqua Arcade 1.3.0 — ocean visual update

The home screen, library and game surfaces now use an ocean palette with aqua controls, scalable glossy tiles and a locally bundled underwater illustration. Merge 2048 uses distinct tile colors; Block Garden preserves the color of each placed piece. The library starts with Block Garden, Merge 2048, Word Search and Color Clash. Existing game rules, local progress, multiplayer and reward eligibility remain intact.

All 36 games, English/Spanish, both themes, reduced effects and offline play are retained. The artwork is bundled in Android and included in the web service worker cache. Web static routes serve the new images. No new app dependency, remote font, analytics SDK or animation loop was added.

## Run or build

Use Node 20 or later. Run `npm ci`, then `npm start`, and open http://localhost:3000. Run `npm test` for automated checks. Run `npm run android:sync` before an Android build; the existing GitHub Actions workflow validates and builds the optimized review APK and unsigned release AAB. Android version is 1.3.0, code 4.

## Verification and release status

- All 74 existing automated tests pass.
- Browser checks open all 36 games without JavaScript errors.
- Light/dark layouts checked at widths 320, 390, 768 and 1280 without horizontal overflow.
- Spanish switching, Block Garden placement, both artwork routes, service-worker offline reload and Merge 2048 offline opening verified.
- Offline asset content is 532.1 KiB, below the existing 600 KiB budget. This is not installed storage or runtime RAM.
- Release through the existing Aqua Arcade GitHub branch and Render service. Verify the deployed commit before reporting the update live.
- Distribute the APK/AAB generated by the GitHub Actions run for this revision. Older Android review packages remain version 1.2.0. Physical-device verification and owner-controlled release signing remain pending.

The underwater hero illustration was created with the built-in image-generation tool using a prompt for a navy/teal coral garden, glossy aqua/coral/lavender/gold puzzle blocks on the right, and clear space for text on the left. It is compressed to a 960 × 640 WebP asset; the game boards remain scalable HTML/CSS and SVG.
